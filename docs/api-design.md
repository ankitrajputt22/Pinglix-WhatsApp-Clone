# API design

All application endpoints use the `/api/v1` prefix.

## Health

### `GET /api/v1/health`

Publicly reports that the Pinglix backend has started.

Response: `200 OK`

```json
{
  "status": "UP",
  "application": "Pinglix",
  "message": "Pinglix backend is running",
  "timestamp": "2026-07-29T10:30:00Z"
}
```

The timestamp is generated by the server in UTC and serialized as ISO-8601.
Database health is available through `GET /actuator/health`.

## Error format

Unexpected controller errors use:

```json
{
  "timestamp": "2026-07-29T10:30:00Z",
  "status": 500,
  "error": "INTERNAL_SERVER_ERROR",
  "message": "Unexpected server error",
  "path": "/api/v1/health"
}
```

No authentication or application-feature endpoints exist in Phase 1.
