# Pinglix UI Direction

## Product Feel

Pinglix should have its own identity. It is not a copy of WhatsApp, Arattai, Telegram, or another messaging app.

The UI should feel:

- Clean
- Modern
- Friendly
- Fast
- Lightweight
- Calm
- Secure
- Reliable
- Responsive
- Original
- Trustworthy
- Professional
- Portfolio-quality

## Design Inspiration

Pinglix can learn from familiar messaging apps.

WhatsApp can inspire:

- Simple private chat flow
- Clear conversation list
- Easy message input
- Comfortable mobile use

Arattai can inspire:

- Friendly and warm design
- Simple onboarding
- Less clutter
- Calm personal messaging

Telegram can inspire:

- Fast conversation switching
- Clear spacing
- Strong empty states
- Clean desktop layout

These ideas are only for usability. The final design must still look like Pinglix.

## What Must Not Be Copied

Do not copy:

- Exact layouts
- Logos
- Brand colors
- Icons
- Product text
- Trademarked images
- Full screens from another app

Pinglix must not claim any link with WhatsApp, Arattai, or Telegram.

## Colors

The main color can use fresh teal, cyan-green, or blue-green.

Other colors can include:

- Cool blue or slate for support colors
- Off-white or light gray for the background
- White for cards and panels
- Dark slate for main text
- Gray for small text
- Soft green for success
- Red for errors
- Amber for warnings

Colors should use Tailwind theme values, CSS variables, or shared design tokens. Random colors should not be added in many places.

## Layout

Desktop:

- Recent conversations on the left
- Active conversation in the main area
- User details at the top
- Messages in the center
- Message input at the bottom

Mobile:

- Show one main screen at a time
- Use a conversation list screen
- Use a separate chat screen
- Add back navigation
- Keep the message input near the bottom

Tablet:

- Use an adaptive layout
- Avoid narrow and crowded panels
- Keep buttons easy to tap

## Design Rules

- Keep it simple before adding more features.
- Make it useful before making it decorative.
- Keep it fast and clear.
- Start with responsive design.
- Use accessible buttons, labels, and headings.
- Keep the design minimal but not empty.
- Use friendly text and clear empty states.
- Keep the experience familiar but original.
- Use the same spacing and corner styles across the app.

Pinglix should feel polished, but it should not feel overdesigned.

## Phase 8 Result

Phase 8 uses one connected app shell for the messaging screen.

- Desktop has a conversation sidebar and a larger chat panel.
- Tablet keeps both areas comfortable when there is enough space.
- Mobile shows the conversation list first and one chat at a time.
- Mobile chat has a Back to Conversations button.
- The current user card is small and easy to scan.
- Search stays available without taking over the screen.
- Message text wraps safely.
- The composer stays simple and supports keyboard sending.
- The real-time status is small and does not mean that another user is online.

No read receipts, typing status, presence, attachments, groups, reactions,
forwarding, message editing, or message deletion are part of this phase.
