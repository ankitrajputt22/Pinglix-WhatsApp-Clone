# Pinglix Roadmap

The following items are possible future work. They are not implemented in the
current MVP.

## Messaging improvements

- Attachments
- Group conversations
- Message reactions
- Message edit and delete
- Push notifications

## Reliability and security

- Redis-backed shared presence for multiple backend instances
- API rate limiting
- CSRF hardening for cross-site production use
- More end-to-end testing

## Release and operations

- Production deployment with a managed database
- HTTPS, domain, backups, monitoring, and secret management
- Horizontal scaling and a shared WebSocket strategy

Pinglix does not currently claim end-to-end encryption, production-scale
reliability, or native mobile support.
